Verrouillage

Accès à cette page : appui long (2 s) ou 5 tapes rapides dans le coin en haut à gauche de l'écran, puis le code.

Verrouiller complètement la tablette Android (épinglage d'écran)
  1. Paramètres → Sécurité (ou « Sécurité et confidentialité » → « Plus de paramètres ») → Épingler les applications → activer, et cocher « Demander le code avant de désépingler ».
  2. Ouvre l'app Memoriz (icône installée sur l'écran d'accueil).
  3. Ouvre les applis récentes, touche l'icône de l'app en haut de sa vignette → Épingler.
  4. Pour sortir : maintenir Retour + Récents (ou glisser vers le haut et maintenir), puis code de la tablette.

Les invités ne peuvent alors ni quitter l'app, ni ouvrir les notifications, ni changer de réglage.

Diagnostic

À vérifier avant chaque événement. Si la caméra USB n'apparaît pas ici, la tablette ne la reconnaît pas.
